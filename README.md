# trend_collector

**요즘 뜨는 것들을 한 번에 모아 하루치 보고서로 만들어 주는 파이썬 스크립트**입니다. 별도 설치 없이 파이썬 기본 기능(표준 라이브러리)만으로 동작합니다.

## 수집하는 곳

| 출처 | 가져오는 것 | 주소 방식 |
| --- | --- | --- |
| 🔥 구글 트렌드 (한국) | 급상승 검색어와 검색량 | RSS |
| 🇰🇷 GeekNews | 한국 개발자 뉴스 | RSS |
| 🌍 Hacker News | 해외 IT 인기글 (점수·댓글 수 포함) | 공식 API |
| 💻 GitHub 급상승 | 최근 7일 안에 만들어진 저장소 중 별이 많은 순 | GitHub 검색 API |
| 🚀 Product Hunt | 새로 나온 제품·서비스 | Atom 피드 |

출처마다 상위 15건(`TOP_N`)을 가져오고, 한 곳이 실패해도 나머지는 계속 진행합니다. 모든 제목에서 자주 나온 단어를 세어 "여러 곳에서 자주 나온 키워드" 15개도 뽑습니다.

## 실행

```bash
python trend_collector.py
```

- 파이썬 3.8 이상. 추가로 설치할 패키지가 없습니다.
- 인터넷 연결이 필요합니다. (API 키는 필요 없음)

## 결과 파일

실행한 폴더 아래 `trends/` 폴더에 날짜별로 저장됩니다. (`trends/`는 `.gitignore`에 있어 저장소에는 올라가지 않음)

| 파일 | 내용 |
| --- | --- |
| `trends/trends_YYYY-MM-DD.md` | 읽기용 보고서: 키워드 → 출처별 목록(제목 링크 + 검색량·점수 등 부가 정보) |
| `trends/trends_YYYY-MM-DD.json` | 다른 프로그램에서 쓰기 위한 데이터 (`date`, `keywords`, `sources`) |

같은 날 다시 실행하면 그날 파일을 덮어씁니다.

## 설정을 바꾸려면

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 출처별 가져올 개수 | `TOP_N` |
| 결과 저장 폴더 | `OUT_DIR` |
| 키워드에서 뺄 흔한 단어 | `STOP` |
| 출처 추가·삭제 | `SOURCES` 딕셔너리에 `이름: 함수`를 넣고, 함수는 `[{title, link, extra}]` 목록을 돌려주면 됩니다 (RSS/Atom이면 `parse_feed(fetch(주소))` 한 줄) |

## 점검 내역 (2026-10)

| 구분 | 내용 |

| 표시 오류 수정 | GitHub 저장소에 설명이 없으면 제목이 `주인/이름 - `처럼 뒤에 하이픈이 남던 것을 고침 |
| README | 저장소 설명이 없어 README 추가 |

### 확인한 것과 못한 것

- 확인함: 가짜 응답(RSS·Atom·JSON)을 넣어 5개 출처 수집 → 키워드 집계 → `.md`/`.json` 저장까지 실행했고, 구글 트렌드의 검색량 태그와 Atom 링크가 올바르게 읽히는 것을 확인했습니다.
- **확인하지 못함:** 이 작업 환경에서는 외부 사이트에 접속할 수 없어 실제 5개 출처에서 데이터를 받아 오는 것은 확인하지 못했습니다. 각 사이트의 주소·피드 형식이 바뀌면 해당 출처만 `[FAIL]`로 표시되고 나머지는 계속됩니다.

## 알아둘 점

- GitHub 검색 API는 키 없이 쓰면 시간당 요청 수 제한이 있어, 짧은 시간에 여러 번 실행하면 `[FAIL]`이 날 수 있습니다.
- Hacker News는 글마다 API를 한 번씩 호출하므로(8개씩 병렬) 다른 출처보다 시간이 조금 더 걸립니다. 글 하나라도 받기에 실패하면 그 출처 전체가 실패로 처리됩니다.
